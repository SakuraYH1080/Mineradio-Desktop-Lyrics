# 0.2.2 设置面板前端更新

本版同步用户认可的最终设置前端，不继续修改设计，也不增加播放功能。

- 保留开放式标题、品牌标识和用途说明；双栏共享主滚动区，窄窗单栏，底部操作区独立。
- 使用粉色、蓝紫及薄荷静态环境背景，颜色延伸至控件后方；输入与选择控件采用透色胶囊玻璃、高光、轻暗边和阴影。不引入背景动画、常驻渲染循环或新的UI依赖。
- 复用 Electron 42.4.1 支持的原生 `base-select` / `::picker(select)`，展开面板有勾选、浅强调色和逐项字体字形。键盘／焦点沿用原生控件机制，减少透明度时提供浅色回退。
- “面板外观 → 面板标题”即时预览，点击原“保存设置”持久化。默认“桌面歌词”，空白自动回退，最多40个Unicode码点，按纯文本显示。旧配置没有字段时自动使用默认；“恢复默认”也恢复该字段，但仍需保存才写入。
- 标题输入只更新面板顶部，不触发歌词预览、字体枚举或播放刷新；仅保存标题时不额外刷新歌词窗口。原EFS保存兼容逻辑保留。
- 状态字幕与占位符、封面／固定配色、字体、黑白字幕预览、Ctrl+Alt+H显隐及Ctrl+Alt+L锁定／穿透保持原功能；长句滚动、同步、header兼容和真实PCM修复保留。

## 更新与发布范围

0.2.1使用者先退出歌词，保留原网易云、插件及自己的配置；将0.2.2解压到可写目录，按README配置同一原版客户端与实际profile即可。发布包不包含个人路径、账号配置或认证文件；不要用旧包覆盖新前端。

本轮只进行工作树／主机部署／公开源码的静态对照、语法及许可检查、ZIP构建和远端版本／附件核对。不运行测试套件，不启动或操作网易云，不采集截图，不开展长时间验证；不据此宣称播放功能测试通过。

源码历史在原main上增量更新，旧v0.2.1标签和Release保留。Electron42.4.1、MineradioBridge0.4.3及其他已说明依赖版本未变；兼容范围仍以README记录为准。
